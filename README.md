# 情報Ⅰサポートツール ネットワーク編

## 高等学校「情報Ⅰ」の学習を支援するための、ネットワーク・暗号・誤り制御・データベースを扱うWeb型教材のポータルサイトです。

「情報の流れを、可視化する。」をコンセプトに、各テーマをインタラクティブなWeb教材として学習できるように構成しています。

## 概要

本アプリは、複数の「情報Ⅰ」対応Web教材を1つのページから利用できるようにまとめた教材一覧ページです。

主な学習テーマは次の5分野です。

### ネットワーク4階層

### パケット交換

### パケット通信

###IPアドレス・ドメイン

###DNS

### 暗号化

### 公開鍵暗号

### XOR暗号

### 誤り制御

### パリティチェック

### データベース

### リレーショナルデータベース

教材一覧から各Web教材へ移動して、個別のシミュレーション・可視化教材を利用できます。

## 主な機能

*1. 教材一覧*

トップページには、各教材をカード形式で表示しています。

カードにマウスを合わせると、浮き上がるようなホバーエフェクトと画像の拡大表示が行われます。

*2. ライト／ダークテーマ切り替え*

画面右上のThemeスイッチから、ライトテーマとダークテーマを切り替えられます。

Light

Dark

選択したテーマはブラウザのlocalStorageに保存され、次回アクセス時にも維持されます。

*3. レスポンシブデザイン*

PCだけでなく、タブレットやスマートフォンでも利用しやすいようにレスポンシブ対応しています。

画面幅に応じて、教材カードの列数やナビゲーション、ボタンなどのレイアウトが変化します。

*4. アクセシビリティへの配慮*

HTMLのセマンティック要素やARIA属性を使用しています。

## 使用技術

本アプリは、外部のJavaScriptフレームワークなどに依存しないシンプルなWeb技術で構成されています。

## 起動方法

特別なサーバーやビルド環境は必要ありません。

### 方法1：HTMLファイルを直接開く

index.htmlをWebブラウザで開くだけで利用できます。

index.html

### 方法2：Webサーバーで公開

GitHub Pagesなどの静的Webホスティングサービスに配置して公開できます。

本アプリ自体はサーバーサイド処理を必要としないため、静的ホスティングとの相性がよい構成です。

GitHub Pagesでの公開

GitHub Pagesを利用する場合は、リポジトリに次のような構成でファイルを配置します。

repository/
├── index.html
├── README.md
└── assets/

    ├── thumb-23.jpg

    └── thumb-27.jpg

GitHub Pagesで公開すると、教材一覧ページから各教材のGitHub Pagesへ移動できる構成になります。

## 教育での利用例

*授業導入*

授業開始時に教材一覧ページを表示し、その日の学習内容に対応する教材を選択します。

例：

ネットワークの授業
        ↓
「ネットワーク4階層」
        ↓
「パケット交換」
        ↓
「パケット通信」

*生徒による体験学習*

教員が説明するだけでなく、生徒自身が各教材を操作することで、抽象的な情報科学の概念を視覚的・体験的に学習できます。

*復習・自主学習*

各教材がWebブラウザから利用できるため、授業後の復習や家庭学習にも利用できます。

*想定対象*

主な対象は次のとおりです。

高等学校「情報Ⅰ」を履修する生徒

情報Ⅰを担当する教員

情報通信ネットワークを学習する生徒

ネットワーク・暗号・データベースの基礎を復習したい学習者

注意事項

本ページは教材へのリンクをまとめるポータルページです。

実際のシミュレーションやインタラクティブな学習機能は、リンク先の各教材で提供されています。

そのため、各教材のURLや公開状態が変更された場合には、本ページのリンクも更新する必要があります。

また、サムネイル画像を追加・変更する場合は、assets/内のファイルとindex.htmlのsrc指定を対応させてください。

カスタマイズ

教材を追加する場合は、index.html内の教材一覧にarticle.cardを追加します。

基本的な構造は次のようになります。

<article class="card">
  <div class="card-frame">
    <a class="card-media" href="教材URL">
      <img
        alt="教材名のサムネイル"
        src="assets/サムネイル.jpg"
      >
      <div class="card-overlay">
        <span class="card-index">09</span>
        <span class="card-host">公開先</span>
      </div>
    </a>

    <div class="card-body">
      <div class="card-topline">
        <span class="card-kicker">Category</span>
      </div>

      <h3>教材名</h3>

      <p>
        教材の説明
      </p>

      <div class="card-footer">
        <span class="card-kicker">教材リンクあり</span>
        <a class="card-link" href="教材URL">教材を開く</a>
      </div>
    </div>
  </div>
</article>
